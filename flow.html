CWBJ FAQ 運用フロー

質問の受付から回答、公開までの流れを一枚で説明するための資料です。質問者と運営、それぞれのToDo、システム構成、費用をまとめています。

01

全体フロー

質問者と運営、それぞれが担当する範囲を分けて示しています。Formsへの送信直後と、「公開」ラベルを付けた後の2箇所は自動処理に切り替わります。

02 / 03

質問者・運営者のToDo

質問者側の作業は最小限。運営側は受付から公開判断までを担当し、公開ラベルを付けた時点で作業は完了する。

質問者のToDo

  1. Formsに質問・相談を入力して送信する（GitHubアカウント不要・匿名可）
  2. 回答を待つ（目安1〜2週間）
  3. 掲載後に取り下げてほしい場合は、再度連絡する

運営者のToDo

受付〜回答
  1. Power AutomateがFormsの送信を検知し、intakeリポジトリ（private）にIssueを起票する自動
  2. 担当者が回答をコメントとして作成する
公開判断
  1. 本文・回答に個人情報が含まれていないか確認し、含まれる場合は編集して伏せる
  2. 他の人の参考になるか、公開してよい内容かを判断する
  3. 公開可と判断したら「公開」ラベルを付与するここから自動
公開後・保守
  1. 取り下げ依頼が来たら、ラベルを外す、またはIssueを削除する
  2. GitHub Appの秘密鍵を年1回程度の目安でローテーションする
04

システム構成

個人情報を含む生データはprivateリポジトリの中に留まり、publicリポジトリへは編集済み・匿名化されたQ&Aだけが渡る。Forms直後とpublicへの受け渡し、2箇所の自動化がそれぞれアクセント色で示されている。

05

費用

想定される利用規模（ラベル起点の軽い自動処理・低頻度の実行）であれば、GitHub Freeプランの範囲内に収まり、実質ランニングコストはかからない。

項目 費用 備考
リポジトリ（private / public） ¥0 Freeプランでもコラボレーター数の上限なし
GitHub Actions ¥0（想定内） privateリポジトリは月2,000分まで無料。想定規模ならまず到達しない
GitHub Pages ¥0 publicリポジトリでのホスティングはプラン不問で無料
GitHub App ¥0 作成・利用そのものに費用なし
Microsoft Forms ¥0 既存のM365テナントを利用
Power Automate ¥0（想定内） 標準コネクタ（Forms・GitHub）のみ使用。M365に含まれる実行回数枠内であれば追加費用なし
合計 実質 ¥0 / 月

Actionsの実行が月2,000分を大きく超えるほど利用頻度・処理量が増えた場合のみ、従量課金（Linuxランナーで約$0.008/分）が発生する可能性がある。現状の想定規模では考慮不要。Power Automateの実行回数枠は契約中のM365プランによって異なるため、正確な上限は管理画面で要確認【未確認】。
